# Analise de Dados de Vendas

## Sobre o projeto.

O projeto tem objetivo de analisar  dados de vendas de uma rede de supermercados, utilizando PostgreSQL, SQL e Python com Pandas.  O fluxo inclui o armazenamento dos dados brutos, tratamento dos dados e análise das informações para responder perguntas de negocios por meio de  estatísticas descritivas e gráficos.

## Tecnologias utilizadas

- Python
- Pandas
- Matplotlib
- PostgreSQL
- SQL
- Git e GitHub

## Como executar o projeto

1. Instale o Python.
2. Instale as bibliotecas necessárias:
   Pandas e Matplotlib
3. Configure o PostgreSQL.
4. Execute os scripts SQL na pasta sql/.
5. Execute os scripts Python na pasta src/.

## Resultados

O projeto responde às perguntas de negócio propostas :

- Filial com maior faturamento: Giza
- Filial com maior quantidade de vendas: Alex
- Linha de produto com maior faturamento: Alimentos e Bebidas
- Linha de produto com melhor avaliação média: Alimentos e Bebidas
- Forma de pagamento mais utilizada: Carteira
- Valor médio das vendas: 322.966749
- Maior venda registrada: 1042.65
- Dia da semana com maior quantidade de vendas: Sábado

## Etapas do projeto

1. Criação do banco de dados e das tabelas no PostgreSQL.
2. Importação dos dados brutos para a camada Raw.
3. Realização das consultas SQL e exportação dos resultados para CSV.
4. Tratamento e transformação dos dados utilizando Pandas.
5. Análise dos dados, estatística descritiva e criação dos gráficos.

## Fonte dos dados

Dataset Supermarket Sales, disponibilizado no Kaggle.
